     你的文字，你的设备
    
        
    留在设备里，
    也可以完整带走。
    
        
    不设账号与云端服务器。提供完整本地导入导出、自动定时本地备份与本地存储体检，换机或 7 天续签也从容不迫。
    
        
    
          
        
    
      
    

      
    
        
    
          01 / 本地导入与导出
          
    Android v2 无损互通、AES-256 保险箱与 Markdown 文集。
    
          
    支持导出或合并/替换导入标准 Android v2 .zip、CryptoKit PBKDF2 + AES-256-GCM .pickupvault 以及百年可读 .md.zip；替换覆盖前自动创建安全回滚快照。
    
        
    
        
    
          02 / 自动定时本地备份
          
    按计划落盘至文件 App、iCloud Drive 或家庭 NAS。
    
          
    支持每 6 小时、每日首选时刻、每周、内容变更防抖与退入后台触发备份，并内置保留份数自动轮换与锁定置顶保护。
    
        
    
        
    
          03 / 本地存储清理与体检
          
    分类统计容量占用，一键回收孤儿冗余媒体。
    
          
    清晰统计文字、照片、视频与备份快照占用的准确字节数，扫描孤儿未引用文件与大体积媒体，保持本地仓库清爽轻量。
    
        
    
        
    
          04 / 自选 AI 零媒体披露
          
    仅发送确认过的文字范围，0 bytes 图片与视频离开设备。
    
          
    每次调用 API 前展示条目数量、纯文本字符数及「0 bytes 媒体发送」确认单，隐私边界一目了然。

     常见疑问
    
        
    开始前的几个问题。
    
      
    

      
    
        
    
          免费侧载 7 天证书到期，日记会丢失吗？
          
    不会。只要不卸载 App，使用同一 Apple ID 重签覆盖安装后所有本地沙盒数据均完好保留；并且你可以在「数据保险箱」开启每日外部目录备份，即使换手机也可随时导入恢复。
    
        
    
        
    
          Android 版 Pickup 导出的 ZIP 能直接导入 iOS 版吗？
          
    可以 100% 无损互通。iOS 版直接解析 Android v2 backup.json、media/ 与旧版 JSON 数组；从 iOS 导出的标准 ZIP 也能回导入 Android，同时通过独立的 ios-extensions.json 保留新增元数据。
    
        
    
        
    
          不使用 AI 功能，能正常长期使用吗？
          
    完全可以。日记记录、Live Photo 实况与视频、红笔时间线、去留、加锁与全部本地导入导出/定时备份均 100% 离线独立运行。
    
        
    
        
    
          可以同时使用黑白深色和黑白浅色吗？
          
    可以。iOS 应用和本页面均支持「墨黑毛玻璃（#080808）」与「素白毛玻璃（#F5F4EF）」双纯黑白外观切换，保持极简一致。
