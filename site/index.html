     01 / 功能矩阵
    
          
    五个模块。
    秩序分明。
    
          
    
            承袭原版 Pickup 黑白极简克制精神，并以瑞士国际主义栅格系统重构信息层级，匹配 iOS 透明毛玻璃质感。
          
    
        
    
      
    

      
    
        
    
          01.1
          
    日记
    Capture
    
          
    
            
    写下片刻想法，附加照片、视频、Live Photo 实况或 Apple Pencil 速记涂鸦，并记录此刻单曲。本地草稿实时留存。
    
            文字 · 实况照片 · 音乐 · 离线检索
          
    
          
        
    

        
    
          01.2
          
    时间线
    Return
    
          
    
            
    瑞士信号红笔在月历上圈出有记录的日子。点选任意日期回看当天片段，自动聚合连续天数与「往年今日」回响。
    
            月历网格 · 红笔标记 · 往年今日
          
    
          
        
    

        
    
          01.3
          
    去留
    Dialogue
    
          
    
            
    每日偶遇一条旧日胶囊或随时随机抽取，阅读当时心境，并在原日记底部追加此刻的跨时空回应。
    
            每日偶遇 · 随机拾取 · 回应写回
          
    
          
        
    

        
    
          01.4

    Consent

            自选模型 · 发送前披露 · 0 BYTES 媒体

     04 / 数据金库
    
          
    留在设备。
    随时带走。
    
          
    
            没有服务器也没有云锁定。提供完整的本地导入导出、自动定时本地备份与逐字节存储体检机制。
          
    
          
    
            
          
    
        
    
      
    

      
    
        
    
          04.1 // 本地导入与导出
          
    Android v2 ZIP、AES-256 保险箱与 Markdown。
    
          
    一键导出或合并/替换导入标准 Android v2 .zip、CryptoKit PBKDF2 + AES-256-GCM .pickupvault 及可长期归档的 .md.zip。替换覆盖前自动留存回滚快照。
    
        
    
        
    
          04.2 // 自动定时本地备份
          
    按计划写入「文件 App」、iCloud Drive 或 NAS。
    
          
    支持每 6 小时、每日首选时刻、每周、内容编辑后与退入后台触发自动备份，附带 SHA-256 完整性校验及历史份数自动轮换。
    
        
    
        
    
          04.3 // 本地存储清理与体检
          
    清晰统计空间占用，一键回收孤儿媒体。
    
          
    精确核算文字、照片、视频与备份快照字节占比，定位缺失引用或孤儿冗余文件并一键释放本地容量。
    
        
    
        
    
          04.4 // AI 零媒体披露机制
          
    发送前纯文本预览确认，绝不上传照片视频。
    
          
    每次 API 调用前展示条数、字符数及明确的 0 bytes 媒体发送承诺单，边界清晰可查。

     06 / 常见问题
    
        
    安装前的
    几点说明。
    
      
    

      
    
        
    
          06.1 // 免费侧载 7 天签名过期后，日记和照片会丢吗？
          
    不会。只要不卸载 App，用同一 Apple ID 重新签名覆盖安装即可原样保留沙盒内容；开启外部文件夹定时自动备份更能双保险防丢。
    
        
    
        
    
          06.2 // 从 Android 版导出的 ZIP 能无损导入吗？
          
    100% 互通。iOS 版直接识别 Android v2 backup.json 与 media/，iOS 专属扩展字段写入独立的 ios-extensions.json 互不干扰。
    
        
    
        
    
          06.3 // 完全不用 AI 服务也能正常运行吗？
          
    可以。图文实况记录、红笔日历、去留回写、应用锁以及全套导入导出/定时备份均 100% 离线工作。
    
        
    
        
    
          06.4 // 墨黑与素白两种黑白美学是否同步内置？
          
    是的。iOS 原生端与展示官网均提供「墨黑毛玻璃」与「素白毛玻璃」纯黑白外观方案，风格彻底统一。
