    04 / DATA SOVEREIGNTY & SCHEDULED BACKUP
    
          
    不设云端服务器，数据主权 100% 握在自己手里。
    
        
    
        
    面向终身留存而设计的本地架构：Android v2 双向无损、CryptoKit 军用级加密、安全书签外置自动备份与存储体检。
    
      
    

      
    
        
    
          01 · ANDROID v2 ↔ iOS 100% LOSSLESS ZIP
          
    与 Android / Web 版 v2 双向无损互通
    
          
    严格兼容 pickup-portable-backup v2 协议（backup.json + media/），同时通过非侵入式 ios-extensions.json 完整保留心情、天气、标签与星标；覆盖恢复前自动生成置顶 .safetyPreRestore 安全回滚快照。
    
        
    

        
    
          02 · CRYPTOKIT .pickupvault ENCRYPTION
          
    PBKDF2 + AES-256-GCM 本地加密保险箱
    
          
    所有文字与媒体先打包后以口令派生密钥（PBKDF2-HMAC-SHA256，80,000 次迭代 + 16 字节随机盐）封装为 AES-256-GCM 密文信封，附带 96-bit 随机 Nonce 与完整性认证标签，防篡改、零明文泄漏。
    
        
    

        
    
          03 · SECURITY-SCOPED EXTERNAL FOLDER
          
    外置目录自动定时备份 · 不惧 7 天续签
    
          
    结合 BGAppRefreshTask 与前后台调度器，按每 6 小时、每日 22:30 或每周自动生成带 SHA-256 校验码的快照，直接落盘至系统「文件 App」、iCloud Drive 或家庭 SMB NAS 的安全书签目录。
    
        
    

        
    
          04 · STORAGE HYGIENE & AI ZERO-MEDIA
          
    孤儿媒体体检与 AI 零图片披露机制
    
          
    内置 DataManagementService 一键扫描孤儿残留媒体与缺失引用、排行最大视频体积；AI Hub 每次发送前强制弹出纯文本披露预览，保证 0 bytes 照片、实况与视频离开设备。
    
        
    
      
    

      
    
        
    
          查阅完整 pickup-portable-backup v2 与 .pickupvault 信封规范
          
    开源透明格式，未来任何时候都可用标准工具解包迁移。
